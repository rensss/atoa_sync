# Android Sync for macOS

这是 Android Sync 的原生 macOS 14+ 接收端和媒体库。

界面默认使用简体中文。可通过主窗口工具栏中的齿轮按钮打开设置，并在简体中文和
英文之间切换。

## 运行

```bash
./macos/build_and_run.sh
```

打包后的应用写入：

```text
dist/Android Sync.app
```

只运行测试、不打开应用：

```bash
swift test --package-path macos
```

## 首次启动

1. 选择接收文件夹。
2. 如果 macOS 弹出提示，允许传入网络连接。
3. 点击工具栏中的二维码按钮。
4. 用 Android 手机的系统相机扫码，并选择打开 Android Sync；手机端会自动更新
   目标 URL。也可以复制应用显示的上传地址并手工填写。

选择文件夹后，应用会自动开始接收。关闭主窗口后，接收端仍会在菜单栏中运行。
主窗口工具栏和传输卡中的 **暂停接收** 会停止 listener 并中断未完成上传；也可从
菜单栏暂停/开始接收。通过菜单栏中的 **退出 Android Sync** 停止整个进程。

## 存储兼容性

macOS 应用的新上传采用按类型平铺的接收端布局：

```text
photos/
videos/
files/
uploads.jsonl
```

文件先流式写入临时 `.part` 文件，只有完整 `Content-Length` 到达后才移动到最终
位置。媒体字节不会被转码或压缩。应用会保留 Android Sync 时间戳、稳定 ID、MIME
类型、来源 IP、JSONL 历史和 `.metadata.json` sidecar。文件系统创建时间和修改时间
按源时间设置，优先级为 `dateModified` → `dateTaken` → `dateAdded` → 接收时间。

已有 `photos/YYYY-MM/`、`videos/YYYY-MM/`、`files/YYYY-MM/` 历史文件不会自动搬迁；
`uploads.jsonl` 中的历史路径仍会继续读取。

选择既有 Python 接收端目录时，会自动导入其中的 `uploads.jsonl` 历史。

## 接收端点

- `GET /`
- `GET /health`
- `GET /manifest.json`
- `PUT /uploads/<filename>`

接收端接受 loopback、IPv4 私有/链路本地地址，以及 IPv6 链路本地或唯一本地地址。
当前没有认证令牌，只应在可信局域网内使用。

地址二维码编码的是 `androidsync://configure?url=...` 应用深链，只包含当前上传地址，
不包含认证信息。Android 端只接受其中有效的 HTTP/HTTPS 地址。不要扫描不可信来源的
配置二维码，以免把后续上传重定向到其他接收端。

## 文件管理

主窗口提供分类筛选、搜索、网格/列表布局、Quick Look、在 Finder 中显示、元数据
检查、重命名、多选和移到废纸篓。选中一个文件后按空格打开 Quick Look；再次按
空格关闭。预览打开后可用左右方向键连续切换当前筛选结果，按 Delete 把当前项目移到
废纸篓；媒体库获得键盘焦点时，网格可用左右方向键逐项移动、上下方向键跨行移动，
列表可用方向键逐项移动，并自动滚动到新选中项。媒体库中也可用 Delete 删除选中项目。
方向键移动只在新选中项离开视口时做最小距离滚动；已经生成的缩略图会在有界内存缓存
中复用，减少连续滚动时的重复 Quick Look 解码。
同步进度只创建一份，固定在内容区顶部，网格、列表、筛选和搜索共用同一个 header；
中间文件完成时继续显示本批进度，最后一个文件完成后立即收起，不再显示完成驻留卡。
删除项目会保留 manifest tombstone，避免 Android 应用再次上传同一媒体。
当前分类和数量由侧栏选中行显示，标题栏不重复展示。标题栏统一控制条包含接收状态、
暂停/开始接收、地址二维码、上下文删除、筛选/排序、网格/列表、设置和 Inspector；
点击状态圆点可查看接收状态、复制地址或暂停/开始接收。日期与排序位于同一个单层
分区菜单中，非默认条件会以强调色图标提示。搜索默认收起为标题栏最右侧的放大镜
按钮，不显示额外圆形背景，并通过弹性间隔固定在窗口顶部最右侧；点击或按 Command-F
后原位展开为带正常输入边界的搜索框。
输入内容会实时筛选文件名；搜索框失去焦点时会自动收回按钮，并保留已有查询和筛选结果。
查询非空时按 Escape 会先清空，再按一次会把搜索框收回按钮。
侧边栏底部会汇总未删除媒体的照片、视频、其他文件数量及其总占用空间；搜索、日期
筛选和当前分类不会改变这组媒体库级统计。

## 版本信息

设置中包含“关于”区域，显示应用版本和构建号：

- 发布版本来自仓库根目录的 `VERSION` 文件，并打包为
  `CFBundleShortVersionString`。
- 构建号来自当前 Git 提交计数，并打包为 `CFBundleVersion`。
- 如果源码不在 Git 工作树中构建，打包脚本会使用正 UTC 时间戳作为构建号。
