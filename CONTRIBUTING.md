# Contributing

All contributors and coding agents must follow `AGENTS.md`.

## Before Editing

Read the required project memory documents, inspect the current Git state, and
choose a batch small enough to review and verify independently.

## Validation

Use the commands documented in `AGENTS.md` and the relevant platform README.
Record skipped or unavailable checks instead of presenting them as passed.

## Documentation

Changes to architecture, risk, roadmap position, protected decisions, or the
next handoff action must update the corresponding file in `PROJECT_MEMORY/`.

## Commits

Keep generated output, local configuration, signing material, and credentials
out of commits. Use a focused commit message that describes the behavior or
governance change.
