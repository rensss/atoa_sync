# B38：Android 相册目录层级与通知点击

日期：2026-09-22

## 目标

让相册白名单按手机目录层级浏览，目录选择可覆盖全部子级并允许进入后细调；点击正在显示进度的
同步通知时打开 Android Sync，同时保持当前传输继续。

## 范围

- `MediaStoreScanner.listAlbums()` 读取每个 bucket 的目录路径，Android 10+ 使用 `relative_path`；
  旧 Android 尝试从 `_data` 文件路径提取相对目录。
- 新增纯 Java `AlbumTree` 模型，负责路径规整、树构建、数量汇总、级联选择和 `NONE/PARTIAL/ALL`
  状态；路径缺失的 bucket 作为根级平铺项。
- 相册页加入目录进入、面包屑、返回上级、文件夹级联选择和部分选择说明；当前目录内的 bucket 仍可
  单独勾选/取消。
- 同步通知设置不可变 `PendingIntent` 指向 `MainActivity`，点击时切回/启动主界面。
- 更新 Android README、项目状态、交接和本批记录。

## 非目标

- 不改变 `album_whitelist` 中按 bucket ID 存储的格式、媒体扫描/上传筛选、同步协议或文件存储。
- 不调整通知渠道/重要性、长按行为或通知动作；不在本批安装 APK 或操作手机，避免打断现有传输。
- 不宣称真机通知导航、厂商通知呈现或相册树交互已经验收。

## 风险和决策

- 检查 R-002：本批构建的是按相册元数据生成的目录树，不遍历或重建媒体队列，不改变其控制措施。
- 未触及 R-001、R-003、R-004、R-007、R-009、R-014 等媒体缩略图、网络、上传和前台服务生命周期控制。
- 不改变架构边界、存储布局或协议，无需新增 ADR。

## 不变量

- 选择结果仍是 `bucket_id` 集合，已保存白名单无需迁移；未知目录路径继续作为平铺相册显示。
- 进入目录只改变选择页位置，不改变选择；当前目录 bucket 可单独切换，父目录复选框始终从后代选择状态推导。
- 通知点击只打开/切回 Activity，不向同步服务发送停止、暂停或重启指令；服务继续由原有前台服务所有。
- 长按与通知渠道行为保持原状。
