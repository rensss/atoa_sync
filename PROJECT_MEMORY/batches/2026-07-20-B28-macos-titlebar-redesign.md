# B28：macOS 标题栏重设计

日期：2026-07-20
分支：`main`
工作基线：`b0092d1`
提交：`54ff01b`

## 目标

解决主窗口标题栏中应用标题、分类、接收状态和多组系统胶囊并列造成的拥挤与层级混乱，
在不改变内部业务逻辑的前提下建立更紧凑、可读的标题栏信息与操作分组。

## 范围

- 使用 unified 无标题窗口工具栏，移除与侧栏导航标题重复的 `Android Sync` 窗口标题。
- 把当前分类、筛选后数量和接收状态合成左侧状态菜单；状态颜色点、暂停/启动、复制
  地址和端口/URL 详情继续保留。
- 把暂停/开始接收、地址二维码、上下文删除、筛选/排序、网格/列表、设置和 Inspector
  收敛到一个带分隔层级的控制条。
- 日期与排序合并到一个单层分区菜单；当前条件继续显示勾选，非默认条件使用强调色图标。
- 为布局按钮增加稳定选中态、按压态、中英文辅助功能文案和稳定的 SwiftUI 身份。
- 更新 macOS README、项目状态与交接。

## 非目标

- 不改变 `AppModel` 的筛选、排序、布局、选择、删除或接收器状态机。
- 不改变二维码编码、上传协议、网络策略、接收器生命周期、媒体存储或 manifest。
- 不关闭 M3 的全量视觉/交互 QA；本批只记录标题栏相关真实窗口检查。
- 不提交或覆盖同一工作区中的 B24–B27 实现。

## 风险和决策

- 未新增风险 ID；本批只重排 SwiftUI View 和主题 token，不触及风险登记要求复核的
  网络、存储、删除实现、manifest 或媒体解码路径。
- ADR-003 保持 SwiftPM/SwiftUI 工具链不变，未增加依赖。
- ADR-007：作为独立 macOS UX 批次记录，可单独审查和回滚。
- M3 仍为进行中；标题栏位置和菜单布局获得了新增人工证据，但 Inspector、双语、
  Quick Look 等全量矩阵尚未在本批重验。

## 不变量

- 五种接收状态及活动上传数量继续由 `statusCapsuleTitle` 和 `statusCapsuleDetail`
  提供；状态菜单仍调用既有 `toggleReceiver()` 和复制地址逻辑。
- 工具栏暂停/开始入口继续复用 B25 的串行接收器生命周期，`.starting` 时保持禁用。
- 二维码入口继续复用 B24 的 `AddressQRCodeButton` 和配置深链。
- 日期筛选、排序方向和默认值不变；菜单项直接写入既有 `dateFilter` / `sort`。
- 删除与清空已删除的显示条件、禁用条件和 action 不变；未执行破坏性 GUI 验证。
- 网格/列表、设置、Inspector、搜索与既有快捷键逻辑不变。
